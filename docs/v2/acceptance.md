# 直接試用 InkHunt v2

開啟 http://localhost:3200/zh-TW 。這是獨立本機環境，資料會真正寫入，頁面重新整理後仍存在；所有帶【測試】或【驗收】的內容都不是正式刺青師資料。

## 消費者

1. 右上角 **Dev Login → 小美**。若目前已登入，先由帳號選單登出。
2. 探索作品，試題材、風格與地區篩選；也可以走「還沒想法？幫我找方向」。
3. 開啟 InkedWolf 頁面，收藏，按「我想詢價」。
4. 填寫想法、部位與大小，選擇預算，可上傳私人參考圖；確認後免費送出。
5. 在「我的詢價」查看對話與報價。接受報價後，等待刺青師提出預約時間。
6. 展開「預約安排」，確認台灣時間與地點，再按「確認預約」。需要時可以取消。

## 刺青師

1. 登出，再由 **Dev Login → InkedWolf 刺青** 登入。
2. 由「刺青師入駐」進入工作室，開啟「詢價」回覆剛才的需求、傳送報價。
3. 消費者接受後，在同一個對話的「預約安排」提出日期時間與地點。
4. 「作品集」可上傳、編輯名稱／風格／題材描述／部位／尺寸／恢復照，以及刪除作品。上傳或儲存失敗可重試。
5. 「個人資料」可管理公開介紹與私人工作室資料。

## 管理員與入駐

- **Dev Login → Harvey**，由帳號選單進入管理後台，可審核 pending 刺青師、核准或停權。
- **New Talent** 是待審核帳號，可檢查審核前管理資料與作品的體驗。
- 想走一次完整新申請，可使用尚未建立刺青師資料的消費者測試帳號，點「刺青師入駐」。

正式 LINE 登入與通知沒有在本機假冒成功；本機用真實 Supabase Auth 測試帳號完成角色驗收。上線前仍須在正式網域驗證 LINE、資料庫遷移及部署設定，詳見 `launch.md`。
